## 1. Что делает скрипт

Берёт входной PDF-файл, накладывает на **каждую страницу** наклонный (20°) повторяющийся текстовый водяной знак «ГИПК «ГАЗ-ИНСТИТУТ»» серого цвета с прозрачностью 5% и сохраняет результат в новый PDF.

### Возможности

- Работает с **любым** PDF (текстовый, сканированный, с формами).
- **Не меняет** содержимое страниц — только добавляет слой поверх.
- **Сохраняет** оригинальные размеры, ориентацию, метаданные.
- **Не портит** кликабельные ссылки, закладки, аннотации.
- Поддерживает **кириллицу** (через TTF-шрифт с Unicode).
- Показывает **прогресс** обработки страниц.
- Работает **офлайн**, без обращений к серверу.

### Что не делает

- **Не распознаёт** текст в сканах (это не OCR).
- **Не удаляет** существующие водяные знаки.
- **Не шифрует** PDF паролем.
- **Не сжимает** итоговый файл (размер может увеличиться на 5–15% из-за наложенного слоя).

## 6. Параметры водяного знака

Все параметры задаются **константами в коде** (в начале файла, после импортов):

```python
WATERMARK_TEXT = "ГИПК «ГАЗ-ИНСТИТУТ»"   # текст
ANGLE = 20                                # угол наклона (градусы)
FONT_SIZE = 64                            # размер шрифта
OPACITY = 0.05                            # прозрачность (0.0–1.0)
GRAY = 0.5                                # цвет (0.0 = чёрный, 1.0 = белый)
```

### 6.1. Как менять

1. Откройте `watermark_pdf.py` в любом редакторе.
2. Найдите блок «Параметры водяного знака».
3. Измените нужное значение.
4. Сохраните.
5. Запустите скрипт.

### 6.2. Рекомендуемые значения

| Параметр | Диапазон | Что влияет |
|---|---|---|
| **WATERMARK_TEXT** | любой текст | Что накладывается |
| **ANGLE** | -45…+45 | Наклон. 0 = горизонтально, 90 = вертикально |
| **FONT_SIZE** | 20…120 | Крупнее = реже, мельче = плотнее |
| **OPACITY** | 0.02…0.15 | Прозрачность. 0.05 — почти невидимый, 0.15 — заметный |
| **GRAY** | 0.0…1.0 | 0.3 — тёмно-серый, 0.5 — средний, 0.7 — светло-серый |

### 6.3. Готовые пресеты

**Едва заметный (для архива):**
```python
ANGLE = 20
FONT_SIZE = 64
OPACITY = 0.03
GRAY = 0.6
```

**Стандартный (как в скрипте):**
```python
ANGLE = 20
FONT_SIZE = 64
OPACITY = 0.05
GRAY = 0.5
```

**Заметный (для служебных документов):**
```python
ANGLE = 30
FONT_SIZE = 80
OPACITY = 0.10
GRAY = 0.4
```

**Диагональный во всю страницу:**
```python
ANGLE = 45
FONT_SIZE = 120
OPACITY = 0.08
GRAY = 0.5
```

**Мелкий частый (защита от копирования):**
```python
ANGLE = 15
FONT_SIZE = 32
OPACITY = 0.06
GRAY = 0.5
```

## 7. Как работает под капотом

### 7.1. Алгоритм

```
1. Открыть входной PDF (pypdf.PdfReader)
2. Для каждой страницы:
   a. Получить размеры (mediabox.width / height)
   b. Создать пустую страницу-«водяной знак» того же размера (reportlab)
      - Заполнить её повторяющимся текстом по сетке
   c. Наложить слой водяного знака на страницу (page.merge_page)
   d. Добавить страницу в writer (pypdf.PdfWriter)
3. Записать результат в выходной файл
```

### 7.2. Сетка текста

- Текст рисуется **в повёрнутой системе координат** (20° против часовой).
- **Шаг по X:** `ширина текста + 50 px`.
- **Шаг по Y:** `FONT_SIZE × 1.3`.
- **Смещение нечётных рядов:** 5% от шага по X (эффект «кирпичной кладки»).
- **Диагональ** рассчитывается как `√(w² + h²)`, чтобы точно покрыть углы.

### 7.3. Наложение

- `pypdf` использует оператор PDF `Do` (XObject), чтобы вставить слой как единый объект.
- Прозрачность (`alpha`) задаётся в `reportlab` через `Color(..., alpha=OPACITY)`.
- Наложение идёт **поверх** содержимого, но **под** интерактивными элементами (если они есть).

### 7.4. Прогресс

В консоли выводится:

```
\rОбработано страниц: 7/12
```

Символ `\r` возвращает курсор в начало строки — выглядит как «живой» счётчик.

## 8. Шрифты и кириллица

### 8.1. Какой шрифт используется

Скрипт ищет **TTF-шрифт с кириллицей** по списку путей:

```python
FONT_CANDIDATES = [
    "C:/Windows/Fonts/arial.ttf",
    "C:/Windows/Fonts/DejaVuSans.ttf",
    "/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf",
    "/usr/share/fonts/TTF/DejaVuSans.ttf",
    "/Library/Fonts/Arial.ttf",
    "/System/Library/Fonts/Supplemental/Arial.ttf",
]
```

Первый найденный регистрируется под именем `WM_Font` и используется для текста.

### 8.2. Если шрифт не найден

В консоль выведется:

```
Внимание: TTF-шрифт с кириллицей не найден — текст может отобразиться некорректно.
```

Скрипт продолжит работу, но использует `Helvetica` — **без кириллицы**. Вместо русского текста могут быть «квадратики» или пустые места.

### 8.3. Как добавить свой шрифт

1. Скачайте любой TTF с кириллицей (например, **PT Sans**, **Roboto**, **Inter**, **Arial**).
2. Положите его рядом со скриптом (например, `font.ttf`).
3. Добавьте путь в `FONT_CANDIDATES`:

```python
FONT_CANDIDATES = [
    "font.ttf",                             # ← ваш шрифт
    "C:/Windows/Fonts/arial.ttf",
    "/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf",
]
```

### 8.4. Где взять шрифт на сервере (без GUI)

**Ubuntu / Debian:**

```bash
sudo apt-get install fonts-dejavu fonts-liberation
# DejaVu попадёт в /usr/share/fonts/truetype/dejavu/DejaVuSans.ttf
```

**CentOS / RHEL:**

```bash
sudo yum install dejavu-sans-fonts
```

**Вручную:**

```bash
mkdir -p ~/fonts
wget -O ~/fonts/DejaVuSans.ttf https://github.com/dejavu-fonts/dejavu-fonts/raw/master/ttf/DejaVuSans.ttf
```

И добавить путь `~/fonts/DejaVuSans.ttf` в `FONT_CANDIDATES`.

## 9. Пакетная обработка

Скрипт **обрабатывает один файл за раз**. Для пакетной обработки — обёртки.

### 9.1. Linux / macOS (bash)

```bash
#!/bin/bash
# batch_watermark.sh

INPUT_DIR="./in"
OUTPUT_DIR="./out"
SCRIPT="./watermark_pdf.py"

mkdir -p "$OUTPUT_DIR"

for f in "$INPUT_DIR"/*.pdf; do
    base=$(basename "$f" .pdf)
    out="$OUTPUT_DIR/${base}_wm.pdf"
    echo "Обработка: $f"
    python "$SCRIPT" "$f" -o "$out"
done

echo "Готово. Результаты в $OUTPUT_DIR"
```

Запуск:

```bash
chmod +x batch_watermark.sh
./batch_watermark.sh
```

### 9.2. Windows (PowerShell)

```powershell
$input  = "C:\PDF\in"
$output = "C:\PDF\out"
$script = "C:\Tools\watermark_pdf.py"

New-Item -ItemType Directory -Force -Path $output | Out-Null

Get-ChildItem -Path $input -Filter *.pdf | ForEach-Object {
    $out = Join-Path $output ($_.BaseName + "_wm.pdf")
    Write-Host "Обработка:" $_.FullName
    python $script $_.FullName -o $out
}

Write-Host "Готово. Результаты в $output"
```

### 9.3. Windows (CMD)

```cmd
@echo off
set INPUT_DIR=C:\PDF\in
set OUTPUT_DIR=C:\PDF\out
set SCRIPT=C:\Tools\watermark_pdf.py

if not exist "%OUTPUT_DIR%" mkdir "%OUTPUT_DIR%"

for %%f in ("%INPUT_DIR%\*.pdf") do (
    echo Обработка: %%f
    python "%SCRIPT%" "%%f" -o "%OUTPUT_DIR%\%%~nf_wm.pdf"
)

echo Готово.
pause
```

### 9.4. Python-обёртка (кроссплатформенно)

```python
# batch.py
import os
import subprocess
from pathlib import Path

INPUT_DIR = Path("in")
OUTPUT_DIR = Path("out")
SCRIPT = "watermark_pdf.py"

OUTPUT_DIR.mkdir(exist_ok=True)

for pdf in INPUT_DIR.glob("*.pdf"):
    out = OUTPUT_DIR / f"{pdf.stem}_wm.pdf"
    print(f"Обработка: {pdf.name}")
    subprocess.run(["python", SCRIPT, str(pdf), "-o", str(out)], check=True)

print("Готово.")
```

### 9.5. Параллельная обработка (для большого количества файлов)

```python
# parallel.py
import subprocess
from concurrent.futures import ProcessPoolExecutor
from pathlib import Path

INPUT_DIR = Path("in")
OUTPUT_DIR = Path("out")
OUTPUT_DIR.mkdir(exist_ok=True)

def process(pdf):
    out = OUTPUT_DIR / f"{pdf.stem}_wm.pdf"
    subprocess.run(["python", "watermark_pdf.py", str(pdf), "-o", str(out)], check=True)
    return out.name

pdfs = list(INPUT_DIR.glob("*.pdf"))
with ProcessPoolExecutor(max_workers=4) as ex:
    for result in ex.map(process, pdfs):
        print("Готово:", result)
```

> Ускорение в 3–4 раза на многоядерных системах. Ограничение — ОЗУ (каждый процесс использует свою память).

## 13. Диагностика проблем

### 13.1. `ModuleNotFoundError: No module named 'pypdf'`

**Причина:** не установлен пакет.

**Решение:**

```bash
pip install pypdf
# или
pip3 install pypdf
# или (в venv)
source venv/bin/activate && pip install pypdf
```

### 13.2. `ModuleNotFoundError: No module named 'reportlab'`

**Решение:**

```bash
pip install reportlab
```

### 13.3. Кириллица отображается как «□□□» или пустые квадраты

**Причина:** шрифт `Helvetica` (fallback) не поддерживает кириллицу.

**Решение:**

1. Убедиться, что TTF-шрифт с кириллицей существует.
2. Добавить его путь в `FONT_CANDIDATES`.
3. Проверить, что имя файла и путь — без ошибок.

**Быстрая проверка:**

```bash
python -c "import os; [print(p, os.path.exists(p)) for p in ['/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf', 'C:/Windows/Fonts/arial.ttf']]"
```

### 13.4. Ошибка `PdfReadError: PDF starts with ...`

**Причина:** файл повреждён или защищён паролем.

**Решение:**

- Проверить, что PDF открывается в Adobe Reader / браузере.
- Если защищён паролем — скрипт **не поддерживает** зашифрованные PDF. Нужно сначала снять пароль (`qpdf --decrypt`).

```bash
sudo apt install qpdf
qpdf --password=ПАРОЛЬ --decrypt input.pdf decrypted.pdf
python watermark_pdf.py decrypted.pdf
```

### 13.5. `PermissionError: [Errno 13] Permission denied`

**Причина:** нет прав на запись в папку / файл занят.

**Решение:**

- Закрыть PDF в Adobe Reader.
- Проверить права на папку:

```bash
ls -la /path/to/folder
chmod 755 /path/to/folder
```

- Запустить скрипт с правами администратора (Linux: `sudo`, Windows: от имени администратора).

### 13.6. Итоговый файл в 2–3 раза больше исходного

**Причина:** накладывается слой с большим числом текстовых объектов.

**Что делать:**

- Уменьшить плотность сетки (увеличить `step_x` / `step_y` в коде).
- Или использовать `qpdf` для сжатия после скрипта:

```bash
qpdf --linearize --object-streams=generate input_wm.pdf output_compressed.pdf
```

- Или `gs` (Ghostscript):

```bash
gs -sDEVICE=pdfwrite -dCompatibilityLevel=1.4 -dPDFSETTINGS=/ebook \
   -dNOPAUSE -dQUIET -dBATCH \
   -sOutputFile=output_compressed.pdf input_wm.pdf
```

### 13.7. Водяной знак не виден

**Причина:** `OPACITY` слишком маленький, `GRAY` близок к цвету фона.

**Решение:**

- Увеличить `OPACITY` до `0.08–0.10`.
- Уменьшить `GRAY` до `0.3–0.4`.
- Увеличить `FONT_SIZE`.

### 13.8. Водяной знак «съедает» текст документа

**Причина:** слишком высокий `OPACITY` или тёмный `GRAY`.

**Решение:**

- Уменьшить `OPACITY` до `0.03–0.04`.
- Увеличить `GRAY` до `0.6–0.7`.
- Уменьшить `FONT_SIZE` — реже, но мельче.

### 13.9. Водяной знак неровно распределён

**Причина:** маленькая диагональ или слишком большой `step_x`.

**Решение:**

- Уменьшить `step_x` (в коде `step_x = text_w + 50` → `+ 20`).
- Уменьшить `step_y` (например, `FONT_SIZE × 1.1` вместо `1.3`).

### 13.10. Медленно на PDF с 500+ страницами

**Причина:** каждая страница создаёт новый `reportlab.Canvas` — это медленно.

**Что делать:**

- Запустить на сервере (быстрее, чем на ноутбуке).
- Не обрабатывать гигантские документы (>1000 страниц) без необходимости.
- Использовать параллельную обработку (раздел 9.5).

### 13.11. `MemoryError` на большом PDF

**Решение:**

- Обрабатывать частями: разбить PDF на куски (например, `qpdf --split-pages=100`), обработать каждый, склеить обратно (`qpdf --empty --pages chunk_*.pdf -- result.pdf`).
- Или запустить на сервере с большим ОЗУ.

## 15. Ограничения

1. **Не поддерживает PDF с паролем** — нужен `qpdf --decrypt` перед запуском.
2. **Не поддерживает PDF/A** в строгом смысле — после наложения могут нарушиться требования PDF/A.
3. **Не работает с PDF, содержащими JavaScript** — скрипт их просто игнорирует.
4. **Размер файла увеличивается** на 5–15% из-за наложенного слоя (не сжимает).
5. **Формы с полями** (AcroForm) — поля остаются рабочими, но визуально могут перекрываться водяным знаком.
6. **Очень большие PDF** (>1000 страниц) обрабатываются медленно и могут исчерпать ОЗУ.
7. **Не OCR** — не распознаёт текст в сканированных документах.
8. **Не удаляет** существующие водяные знаки (не «заменяет», а «добавляет»).
